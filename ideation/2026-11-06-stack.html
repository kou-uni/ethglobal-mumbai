What we stand on — protocol, tools, product

There are seven layers. We built only three; the rest are borrowed. This one page covers what happens when a borrowed layer goes down, and the fallback for the filming day.

2026-11-06kouMark [verified] = run and checked on this machine today

Executive summary

  1. We built three layers: the device app, the gate (Broker), and the screens. The other four (sealed inference / proof of personhood / ledger and storage / delivery) are borrowed, and each sits in a position where it can be swapped out.
  2. When a borrowed layer goes down, we do not lie about it. If 0G goes down, STOPPED; if World goes down, no flame is issued; if Storage goes down, the trail stays in the Broker. There is not one path that hides a failure and passes anyway.
  3. Today, a write to 0G Storage went through [verified]. root 0x3b28…6244 / tx 0x8b0a…3916. The gas arrived, so the trail really is on the chain.
