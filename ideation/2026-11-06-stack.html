03落ちたら何が起きるか

借りものが落ちる前提で、落ち方を先に決めてある。「たぶん大丈夫」で通す経路は作らない。

落ちるものその瞬間の振る舞い人に見えるもの撮影当日の退避
0G（推論）判断を作らない。回数も減らさないSTOPPED「決められないので止めた」退避しない。むしろ図04として見せる
World灯が出ない。既にある灯は消えない断りは human_denied、時間切れは proof_expired灯の場面は録画で見せる（登録が間に合わない場合）
0G Storage系譜は Broker に残る（追記のみ）「0G Storage に置けていない」と出す今日 tx が通った【確】ので、当日は本番で出す
実機（Ledger / bridge）署名が取れない＝通らない画面に「実機の代わり」と明記して代役で署名代役（決定 Q3-b）。黙って代役にしない
外部 API（Stripe 等）代理実行は EXECUTE=0 で止めてある判定までを見せる公開時は SECRETS 空・EXECUTE 切り
GitHub Pages画面が開けない—ローカルの python3 -m http.server と録画
