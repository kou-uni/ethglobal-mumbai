    系譜（追記のみ）

      この画面は試作。デザインは minta さんが仕上げる。ここで決めているのは「何が、どの順で、どれだけ大きく見えるか」だけ。

      0G Private Computer は飾りではない。重さを決めるには要求の本文を読む必要があるが、その本文を我々に見せたくない。だから封印（TEE）の中で読ませている。判定ごとに request id が出て、上の表に載る。

      届かないときは判断を作らない。既定値も、その場の推測も出さない（STOPPED）。偽の判断は、通してしまうのと同じくらい悪い。
