# 画面を1つの筋にまとめる案（minta）— 2026-11-06

Kou さんの `ui/`（門・灯の試作）と、minta の `web/`・Ledger アプリ・bridge を読み比べた。
**結論：ぶつかっていない。足すと1本になる。** 門は Kou さんのものしかなく、実機とつながる部分は minta のものしかない。

## 1. どちらに何があるか

| 見せたいこと | Kou さんの `ui/` | minta の `web/`＋実機 |
|---|---|---|
| 0G が中身を読んで重さを決める（4通りの止まり方） | **門。本番の 0G の応答で動く** | ない |
| 手元で押す | 画面の「押す」ボタン。署名は**ソフトの鍵**（`0x11…`）であらかじめ作ってある | **実機 FLEX の長押し。** 画面 → bridge → 実機 → Broker が通っている |
| 範囲外を止めたことが手元に出る | 門の中に `DENIED` と出る | **実機が白黒反転して `BLOCKED`** |
| 灯（誰が使っているか） | 1つの道具に灯が7本。**数**を出す。値は試作の持ち値 | 空。`Everyone`（買える星）と `People I know`（知っている人の灯）の切り替え。Broker から読む |
| 記録 | 門の右下に系譜の列 | 記録の画面。**QR でスマホに渡せる**（公開のリンク。確認済み） |
| 言葉と見た目 | 日本語・白地。「minta さんが仕上げる前の試作」と書いてある | 英語・夜の色 |
| 公開の場所 | `kou-uni.github.io/ethglobal-mumbai/ui/` | `mintannn.github.io/tomoshibi/` |

## 2. 気になる点が2つ

1. **門の「押す」は、いま実機を通っていない。** 筋書き §6 にも「まだ同じ画面で繋がっていない」とある。
   このままだと、いちばんの見せ場（AI には押せないボタン）が画面のボタンになり、実機は別撮りになる。
   **つなげられる。** 門が `NEEDS_PRESS` を受けたら bridge の `/permit` を呼び、実機の署名で `/use` を投げ直す。`demo-ledger.mjs` が同じことをもうやっている。
2. **灯の画面が「数」に戻っている。** 筋書きは「だから数が『いま使われている』を指す」。
   #7 で決めたのは「**空に星の数は出さない。数ではなく誰の星か**」。World の賞に効くのも「誰の」のほう。
   版が上がると一斉に消える、は `web/` にもある（`Demo: the tool changes`）。
