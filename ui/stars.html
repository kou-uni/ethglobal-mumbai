Going out is the feature. When the version changes, flames on the previous version stop counting. Only people still using the skill notice and give one again. So the flame count says "in use now", not "was good once".

This screen is a prototype. minta will finish the design. The counts and state come from the Broker's GET /stars/<skill>?version= ("Read from Broker" really fetches it).

World verifies only that you are a human, and the same human. What you gave a star to, and which key was involved, never reach World. A star records nothing but a per-sector pseudonym (sub).
